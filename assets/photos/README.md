# Echte Familienfotos

Fotos, die hier liegen, ersetzen automatisch das generierte Bild der jeweiligen Szene
(Hoch- oder Querformat, JPG oder PNG). Danach einfach neu rendern.

| Dateiname          | Szene                                                      |
|--------------------|------------------------------------------------------------|
| `bartek_baby.jpg`  | „jego syn, Bartek“ – Baby- oder Familienfoto von Bartek (2008) |
| `together.jpg`     | „Od tego dnia ich historia stała się wspólna“ – Vater & Sohn |
| `best.jpg`         | „Tato, wszystkiego najlepszego“ – das schönste gemeinsame Foto |

Hochformat-Fotos werden mittig auf eine weich unscharfe, abgedunkelte Kopie
ihrer selbst gesetzt; Kamerafahrt, Grading und Film Grain laufen genauso darüber.
